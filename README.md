
# Multilingual Translation System 🇳🇬

## Project Description

The Multilingual Translation System is a Python-based project designed to translate common English words and phrases into five Nigerian languages: Igbo, Hausa, Yoruba, Idoma, and Tiv.

The project aims to promote Nigerian indigenous languages, encourage cultural diversity, and make communication across different language groups easier.

## Supported Languages

1. Igbo
2. Hausa
3. Yoruba
4. Idoma
5. Tiv

## Features

- Translate individual English words and phrases.
- Select a preferred Nigerian language.
- Display all available English words.
- View all translations in a selected language.
- Change language without restarting the program.
- Interactive command-line interface.
- Input validation and error handling.

## Available Words and Phrases

The system currently supports 20 English words and phrases:

## Technologies Used

- Python 3
- Python Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input and Output


## How It Works

1. The program displays a welcome message.
2. The user selects one of the five available Nigerian languages.
3. The main menu displays five options.
4. The user can translate an individual word, view available words, or translate all 20 words.
5. The user can change the selected language or exit the program.
